# Known Issues and Limitations

| # | Area | Issue | Plan |
|---|---|---|---|
| 1 | Verification | **Phases 3 to 10 have not been run in the Unity Editor.** Core logic is covered by 161 headless tests and the balance simulator; Runtime and Editor code (Phase 8 especially) is only type-checked against Unity reference assemblies. Expect some layout, timing and visual issues on first play. | Run the full-game checklist in TESTING_LOG.md. |
| 2 | Project files | `Packages/`, most of `ProjectSettings/` and `.meta` files are generated by Unity on first open and must be committed by whoever opens it first (README step 3). | One-time setup. |
| 3 | Balance | The game is very hard by design, and the simulator's scripted bots almost never win (see TESTING_LOG.md). True-odds payouts keep each bet's expected value near the house edge, so winning needs a few lucky long-odds hits, loopholes, contracts and challenge rewards. Human play may differ from the bots. | Tune from play: `RunConfig` money and rounds, installment fractions in `PaymentSchedule`, rewards in `Challenges.cs`, prices in `ShopCatalog`, rule costs via `RuleCatalog.Tune`. |
| 4 | UI | The whole interface is IMGUI: functional, not the final animated UI. Panels can overlap on small or narrow screens; use the UI scale slider in the pause menu. | Replace with uGUI or UI Toolkit. |
| 5 | Input | IMGUI panels block table clicks through `UiPointerBlocker`, which uses the previous frame's panel rectangles. A click in the first frame a panel appears could reach the table. | Goes away with the final UI. |
| 6 | Audio | All sounds are synthesised placeholders. The Game Master has no recorded voice; a low murmur plays instead. | Drop clips into `Resources/Audio/<cue>` and `Resources/Voice/gm_<line id>`; they override automatically. |
| 7 | Rooms | Rooms are panels over the table (by design: table only). Game Master "sightings" are text in the room panel, not 3D. | Short transitions or vignettes later, if wanted. |
| 8 | Saves | The run saves only between rounds. Quitting mid-round resumes from the start of that round's state before it began (bets placed in the unfinished round are not kept). | Acceptable for now. |
| 9 | Labels | Number and wall labels use Unity's built-in font through `TextMesh`. If numbers look too big or small, adjust `WorldTextFont.LabelScale`. | TextMeshPro later. |
| 10 | Highlight | If a prototype material's emission is switched off in the Inspector, focus highlights stop glowing on that material. | Outline effect later. |
| 11 | Ability hotkeys | Abilities define hotkeys in data, but only the on-screen buttons trigger them (number keys already switch camera views). | Rebindable input map. |
