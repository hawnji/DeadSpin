# Known Issues and Limitations

| # | Area | Issue | Plan |
|---|---|---|---|
| 1 | Verification | Phase 2 has not yet been run in the Unity Editor; Runtime/Editor code is type-checked only, and the WorldText shader was not compiled here. | Run the Phase 2 checklist in TESTING_LOG.md. |
| 2 | Project files | `Packages/`, most of `ProjectSettings/` and `.meta` files are generated by Unity on first open and must be committed by whoever opens it first (README step 3). | One-time setup. |
| 3 | Highlight | If a prototype material is edited in the Inspector and its emission is switched off, focus highlights stop glowing on that material. | Replaced by an outline effect in Phase 8. |
| 4 | Input | Clicking a HUD view tab also counts as a click on whatever is behind it on the table (usually nothing, at the top of the screen). | Fixed when the HUD moves to uGUI/UI Toolkit, which blocks pointer events. |
| 5 | Labels | Number labels use Unity's built-in font through `TextMesh`. Their size is set by an approximate formula; if numbers look too big or small, adjust `WorldTextFont.LabelScale`. | Replace with TextMeshPro in Phase 8. |
| 6 | UI | IMGUI HUD is functional but not the final animated UI. | Phase 8. |
| 7 | Audio | No audio yet; the wheel and ball are silent. | Phase 8 (wheel and chip sounds may land earlier with their systems). |
